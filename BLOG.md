# Automate Your XRPL Trading: Introducing the Sologenic Community Node for n8n

We're excited to announce the release of our latest community node for n8n: the Sologenic integration! Built by Velocity BPA, this node brings the power of the XRP Ledger's leading tokenization ecosystem directly into your automation workflows.

## What is Sologenic?

Sologenic is a sophisticated ecosystem built on the XRP Ledger (XRPL) that offers SOLO token management, decentralized exchange (DEX) trading, and an NFT marketplace. For traders, investors, and businesses operating in the XRPL space, Sologenic represents a powerful platform for digital asset management.

## The Automation Gap

Until now, integrating Sologenic operations into automated workflows required custom coding, complex API implementations, or manual intervention. Whether you're monitoring SOLO token prices, executing trades based on specific conditions, tracking NFT marketplace activity, or managing portfolio data, these tasks consumed valuable time and technical resources.

That's where our new n8n node comes in.

## Key Features

The n8n-nodes-sologenic package enables you to:

- **Monitor SOLO Token Activity**: Track price movements, volume, and market data in real-time
- **Automate DEX Trading**: Execute trades based on custom triggers and conditions
- **NFT Marketplace Integration**: Query NFT listings, sales, and marketplace events
- **Seamless XRPL Integration**: Leverage the speed and efficiency of the XRP Ledger
- **No-Code Workflow Building**: Connect Sologenic with hundreds of other services without writing code

## Getting Started

Installing the Sologenic node is straightforward. In your n8n instance, run:


npm install n8n-nodes-sologenic


After installation, restart n8n, and you'll find the Sologenic node available in your node palette.
